# Cómo agregar o actualizar tu información

## Opción 1: Pull Request (recomendada)

1. Haz un fork de este repositorio.
2. Edita `data/miembros.csv` y agrega una fila con tus datos.
   - Mantén el orden alfabético por `id`.
   - Usa `;` para separar varias áreas de interés dentro del campo `area`.
   - Si tu institución no aparece en `data/instituciones.csv`, agrégala también.
3. Abre un Pull Request describiendo el cambio.

## Opción 2: Issue

Si no te sientes cómode editando archivos en GitHub, abre un Issue con el
título "Nuevo miembro: Tu Nombre" e incluye los campos que quieras compartir.
Alguien del equipo hará el cambio por ti.

## Reglas simples

- Solo se agrega información que la propia persona autoriza publicar.
- Para eliminar tus datos, abre un Issue o PR pidiéndolo; se hará sin preguntas.
- Los campos opcionales pueden quedar vacíos, pero conserva todas las comas
  del CSV para que el número de columnas sea siempre el mismo.
